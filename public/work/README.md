# Portfolio screenshots

Put the real website captures here, then reference them in `src/data/content.js`:

| Project            | Desktop (browser frame)         | Mobile (phone frame)           |
| ------------------ | ------------------------------- | ------------------------------ |
| Teddy Bike Samui   | `teddy-bike-desktop.webp`       | `teddy-bike-mobile.webp`       |
| Samui Property 360 | `samui-property-360-desktop.webp` | `samui-property-360-mobile.webp` |
| Valérie d'Art Don  | `valerie-dart-don-desktop.webp` | `valerie-dart-don-mobile.webp` |

```js
image: '/work/teddy-bike-desktop.webp',
mobileImage: '/work/teddy-bike-mobile.webp',
```

Tips: capture the desktop page at about 1440px wide and the mobile page at about 390px wide.
Full-page (tall) captures work best, because the frames scroll through them on hover or tap.
Keep each file under about 300 KB (WebP, quality around 80).
